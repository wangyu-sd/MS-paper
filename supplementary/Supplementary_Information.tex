\section*{Supplementary Note 4: Reaction-state search and computational diagnostics}

\section*{Supplementary Note 5: Fragmentation and spectrum comparators}
Report exact versions, parameters and interfaces for exact-mass, opportunity-normalized, forward-spectrum, CFM-ID/SIRIUS-derived and other final peer-reviewed comparator methods. All comparator analyses must use identical spectra and candidate pools.

\section*{Supplementary Note 6: METEOR and Chemical-World/Spectral-Reality training}
Report the final METEOR architecture, chemistry-specific vocabulary, continuous mass conditioning, peak-token spectrum encoder, training stages and checkpoint selection. Clearly separate structure-only adaptation, Chemical-World proposal supervision, Spectral-Reality experimental supervision and evidence-guided post-training.

\section*{Supplementary Note 7: Spectrum-identity and structured-reasoning controls}
Report correct/no-spectrum/shuffled-spectrum construction and the parent/pilot $\times$ normal/no-reasoning/shuffled-reasoning six-arm analysis. Include molecule-group aggregation, bootstrap/sign-flip inference, multiplicity correction and non-target gates. The six-arm analysis is supporting implementation evidence rather than a principal manuscript claim.

\section*{Supplementary Note 8: Reciprocal adaptation and endpoint controls}
Provide the ORBIT state machine, frozen snapshot identities and exact promotion gates. Report the factorial endpoint design $(H_0,E_0)$, $(H_T,E_0)$, $(H_0,E_T)$ and $(H_T,E_T)$, the interaction effect, fixed-side controls, ungated/blind-alternation control, replicate runs, frozen anchors and success-bank preservation. The cross-generation matrix is computed only after snapshot freeze.

\section*{Supplementary Note 9: External transfer and risk-controlled structural sets}
Report exact external candidate-source versions and inference settings, demonstrate that pLSE was not used to sample/rerank them, and provide same-formula/near-isomer transfer results. Report generator recall, conditional discrimination, end-to-end resolution and the final split-conformal/risk-control procedure with empirical coverage and set-size diagnostics.

\section*{Supplementary Note 10: Mouse metabolomics cohort}
Report source study, animal/sample metadata, ethics, LC--MS/MS acquisition, raw-data conversion, feature detection, blank/QC filtering, spectrum cleaning, blinded-anchor construction, frozen library-search definition of dark spectra, recurrence criteria and orthogonal validation. Provide complete alternative-candidate dossiers for all structure-level case studies.
